# AlephBot

## Description
This project initialized due personal use for my Discord server. This project use Node.js and Discord.js as the main foundation of the bot with Pino as the logger.

## What's New?

### Basic Foundation
- Initialize the project using **npm init command**.
- Create and add modules that shouldn't be uploaded on GitHub.
- Make a recursive module to list the file paths.
- Create an .env and make a file that configure how the bot works.
- Configure a logger and its types.

### Modulations
- Provide commands, events, handlers, and database folder.
- Make the nessecary handler such event, command, and component loader.

### Database Connection
- Provide the nessecary events such ready event.
- Create a log flush and transport end function.
- Make an error and shutdown listener.
- Create a schema model using mongoose library.
- Run a service and repository of the schema model.
- Initialize connection to database.
- Write a documentation (too late, but at least it's now or never).
